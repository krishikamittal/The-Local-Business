# The-Local-Business

A small mountain bakery-café based in Nainital, made around the idea of slow mornings, warm bakes and good conversations.

This project was created as a **Local Business landing page** for the BITBOX 7.0 Web Development task.

## ✦ What's inside?

* Bakery & café menu with category filters
* Pahadi Pick — an interactive food recommendation game
* Secret Wall where visitors can leave a thought or memory
* Opening hours, location and contact details
* Responsive layout for desktop and mobile
* Google Maps directions

## 🥐 Menu

The menu focuses mainly on bakery items, snacks and drinks rather than full meals.

Some of the items include:

* Kafal Crumble Muffin
* Snowline Chocolate Roll
* Buransh Lemon Loaf
* Mallital Cheese Melt
* Jungle Masala Fries
* Nainital Wali Cutting Chai
* Fog & Foam Latte
* Lake Side Nimbu Fizz

You can also use **Live Server** in VS Code for a smoother development experience.

## 🌿 Concept

Kafal & Chai is a fictional café created around the feeling of finding a small, warm place while travelling through the hills — somewhere you stop for a chai, a pastry, and maybe leave with a little memory.
